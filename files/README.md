# Files

Put PDFs (and other static files) in this folder.

A file named `example.pdf` is published at:

`https://bapuji.xyz/files/example.pdf`

On the site, link it from `_data/links.yml` as `/files/example.pdf`.

Replace `example.pdf` when you add a real document, and update or remove the example entry in `_data/links.yml`.
